# NAP-LINE-2026-10-30.txt: the first nap, one line at the user's prompt. The hop trace of ended runs goes (the landings; the hits that carried no call and no spawn); the receipts stay, so every run can still be replayed hop by hop; running runs keep their trace. Nothing reads land after its trigger; hit is read only where it carries a call (the standing question shape). Tried on a copy of the live brain: 2,692,807 landings and 2,673,210 hits gone in 3.2 s, the same lines answered identically after. Not typed into the live brain by me: it deletes rows of the owner's brain, so it is the owner's to type. The file shrinks only after a VACUUM (the brain asleep for minutes; at the terminal: sqlite3 brain.db VACUUM while the door is stopped); until then the freed pages are reused.
BUILD DELETE FROM land WHERE run IN ( SELECT run FROM run_memory ) ; DELETE FROM hit WHERE call IS NULL AND spawn IS NULL AND run IN ( SELECT run FROM run_memory ) ; SELECT changes ( ) ; BUILD
