## New and re-taught (MY READING of the owner's words; taught lines he can retype)
- find : memory last | memory "v" | formula last | formula "v" | definition w | relation w | place w   (also without the colon:
  "find memory last" etc., bound the same way). memory: the last memory row, or up to 5 whose line holds v; formula: the last formula,
  or formulas whose word is or holds v, each with its run's path; definition: w's definition memories and their marks; relation: w's
  relation rows; place: w's live place.
- apply : x rel... y   writes the relation row (x, rel, y) as given ("apply : learn like study").
  apply : x            writes x's relation rows from its map source definitions ("like shop" -> (x, like, shop)).
- update definition : x  marks x's current first definition memory wrong (kept), then says the next one. define : x is re-taught to skip
  definitions marked wrong (the old define: row is ended and kept: a truth shift).
- run backpop (re-taught)  for every relation row of kind like / alike / similar: the word without a formula gets the other's formula
  (a formula row of origin backpop pointing at the same run), both directions; and for the word of the newest such relation, its DNA
  rows that carry a trigger are laid, with the same trigger, in each alike word's table (through mother). Then it says how many.
