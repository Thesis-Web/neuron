## Built (hp2 commit 9d02842; patches c16, c16b, c16c, c16d, c16e beside this file; c16-test.sh the exact commands)

- **The receipt.** `df -h / | cortex receipt audit 1 df -h /`: the machine's own print, piped in, typed as receipt lines and kept as the checkpoint's ground. A model's hand never retypes it. A print judges only a claim made after it; a later print confirming an earlier value counts; a later print that differs is a label ("no print at its time; the newest print reads ..."), not a verdict against the earlier claim.
- **Sources.** `cortex source <name> owner|reference : <what, where from, as of>` then `cortex source <name> -` types its sentences (build time, no judge, no text copy kept). In: the owner's 574 messages (19351 sentences, 224.7 s) and the frozen handler (167 sentences, 3.2 s).
- **Ground cells** per word gate: receipt, owner, reference, memory (any project of the brain), none; per number: printed by the machine or not.
- **The formula**, in order: noise; the kernel's same_as; echo; a value the machine never printed, said after the print = hallucination by receipt; supersede; drift; every value printed and the expected's shape = completes by receipt; the shape's completes only where no print preceded the claim; every value printed and two of the receipt's own words = progresses by receipt; the learned weights; haiku last. A judgment cell never moves state; the receipt, the shape or the owner's accept does.
- **The question.** Two or more words with no ground = a typed question, listed by `cortex questions <project>`, shown in the hydration as OPEN QUESTIONS, answered by `mark`, `accept`, `reject` or a source that holds the words. A worker never guesses them.
- **The label.** Every part in ACCEPTED SO FAR: `[time pX judge | receipt 3 owner 7 reference 3 memory 9]`; RECEIPTS shows the newest print per command.
- Also: values in the restate key (a line differing only by its value reaches the judge); a part the owner rejected never retires another; `reject` restores what the rejected run superseded; `cortex verdicts` has a ground column.
