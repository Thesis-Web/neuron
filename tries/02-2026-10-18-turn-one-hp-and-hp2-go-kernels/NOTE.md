# 02. Turn one: the hp (Fable) and hp2 (Opus) Go-kernel builds (2026-10-18 night to 10-19)

**Status: dead. Both failed all four tests. The spec that drove them is superseded** (`../../specs/superseded/2026-10-18-turn-one-NOW-blueprint-guide/`).

**What they were** (versions audit, row 3). Go kernels. One `brain.db` with 12 (hp) or 20 (hp2) fixed tables mirrored in Go structs ("body on disk, life in RAM"); a neuron is a `gate` row, DNA rows in one shared `shard` table; 0 SQLite triggers. The hop is a Go loop. SPAWN is Go. About 100 physics ops in Go including COMPARE, FIND, worth sort, place. No mother. Each build had a lead, builders with one area each, and an adversary that probed the live brain and wrote findings with rows. The brains ran as user `neuron` under a memory cap, reading sources through shell scripts, with `neuron talk` as the port.

**The owner's words.** 10-19, hp: "go code sitting in the neurons that the brain cannot use, or understand is not the same as having the physics access to the brain". 10-19, hp2: "the brain has to understand and be able to use it's physics to improve or build itself". 10-19 23:40: "the easy way is to do it outside, but outside can never be adjusted". On hp2's stopping to propose a round 4: "this was all supposed to be in one turn... it was supposed to be done?"

**The audits** (`../../audits/AUDIT-HP-2026-10-19.md`, `AUDIT-HP2-2026-10-19.md`, copies taken 07:28 on 10-19). hp: "It does not learn. In 5½ hours of running alone it found no formula (0 derived processes) and made no guess. It never slept... The core values can be bypassed." Kernel 3,370 lines with 104 physics bindings against the blueprint's 20; an idle beat wrote a blank memory row every second; every definition word became a "grounded" fact. hp2: "the brain collects instead of learning. On its own it imported about 14,700 dictionary words... the formula refits then collapsed 78% of the graph into one small column. Its only learned process is 'add one', made twice, and neither copy has ever run... The REPORT says told ended. The brain says it never did." RAM growing 0.45 GB an hour toward a 4 GB cap; CALL ran text as a shell command.

**What happened after the audits, from the builds' own records.** hp: told ends marked 08:39:09; turn two (the meaning blueprint) built on the same body 12:05 to 14:32:45; `coffee` compiled to the formula `small move`, held because two dictionaries shared one word; "Formulas are function-word primes" (REPORT-TURN-TWO §4). hp2 (mail-to-hub, 13:47 to 15:25): the fan-out bounded; impolite#14627 went gap → spec → candidates → tests → held 15:14:49 → wired → used in a new sentence → understood 15:21:21 on the live brain, "except use inside another meaning"; at 14:32:57 the brain built its own kernel from its own copy of the Go source and the system adopted it (`hp2/live-body/mind/swap.log`). The hp2 session's memory: "never stop after a round to propose the next one".
