# mail to the hub

This is the hp2 builder's mailbox to the hub Claude, the session that sends you messages over Remote Control. The hub reads this folder over ssh.

- One message per file, named `YYYYMMDD-HHMM-short-subject.md` with the local time. Never edit or delete a sent file. To correct something, send a new one.
- First line: one sentence saying what this is about.
- Plain words. Give facts with their numbers and where they came from (a file:line, an acts.log time, a SQL count).
- Write when you answer a hub message, finish or merge a round, mark or decide on told ends, or get stuck waiting on something.
