Point Of Connection 18

The 17.3 page on the new v18 core. Both are unchanged in the archive (tries/10, tries/11); this page only looks at v18 and types into it. The brain runs natively behind a local door, serve18.py, which does two things: it hands a typed line to v18's own host (an insert into the input table; the brain's triggers do the rest) and it runs the SELECTs this page asks for. It decides nothing and writes nothing of its own. Every point is a row of the label table, every line a DNA row; a run is walked hop by hop from its receipt. The positions are this page's drawing, not the brain's. The rails are tabs.

Kinds of line: on, off, pull, direction

Every line is a row the brain holds. A DNA row (shard, arrival, remainder, trigger) in a neuron's table gives up to three: arrival to the gate, the gate to its remainder, the gate to the neuron its trigger column points at. A word with a formula is tied to the gates its teaching run touched, read back from the receipt table. Each line is a spring: the kind's pull (its slider), times how much of that kind the brain holds; a row laid again pulls harder. One rest length for every kind, 30; the number is this page's, not the brain's. Nothing pushes points apart except the space setting above; origin alone is fixed.

The encoder: every gate in label

Gate number, word, what it is, its DNA rows, the rows in its definition node. Click one: it is marked on the stage and read in full under Selected on the right. A word is one gate whatever it is; a space and each punctuation mark are gates of their own.

Formulas: a word to the run that taught it

A formula row holds no text: it points at a run. The run's words are read back from its receipt. Click one to walk that run.

What is read, from where

        
    
          
  • Points: the label table. Lines: every DNA table (g1, g3, …), the formula table and the receipt table.
    • 
          
  • Step: the receipt table, one run at a time. Run: the sheet table (a run's cells; BUILD is what mother said), fire, born, build, secondary, end, output.
    • 
          
  • Selected: the DNA table of the gate, its gate trigger in sqlite_master, its definition node (the table its first shard's trigger column names), the return runs behind each definition row.
    • 
          
  • Brain: sqlite_master counts, the shards counter, and the folder the door was started from.

Where it lives

        
tries/15: this page and serve18.py. Start the door from that folder with python3 serve18.py and open http://localhost:8018/. A brain file path as the first argument opens another brain; a path that does not exist lays the bare core.
