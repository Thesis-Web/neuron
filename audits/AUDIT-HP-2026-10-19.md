# AUDIT of the hp build (Fable), turn one

*Outside audit, 2026-10-19. The builders' copies of the brain, kernel and lay files were taken at **07:28**, before this turn's changes, and read only on another machine. Nothing on hp was touched or run. Six read-only auditors checked them against NOW, the blueprint, the guide and the update note. I re-checked the headline findings by hand. Each finding gives the evidence (file:line, or a query on the body and its result) and the scope line it breaks. Where the build's own FINDINGS.md already has the item, it says "still open (their #N)".*

**How to use this.** Fix by making the brain correct, never by working around a finding. Don't add more told knowledge to cover a gap: several findings below *are* told knowledge. Settled scope stays settled.

---

## Verdict in one paragraph

- **The machinery is broad.** It has a timeline, spawning with a birth memory for every gate, placement that moves on relationships, 17 sources and core rows, and the brain is now running safely inside a memory cap.
- **It does not learn.** In 5½ hours of running alone it found **no formula** (0 derived processes) and made **no guess**. It never slept, and it never worked one of its 13,603 imbalances.
- **What it did instead.** It walked gate ids one a second and wrote a blank memory row each time. It turned every word of every definition into a "grounded" fact.
- **The core values can be bypassed.**
- **None of the seven day-one abilities fully shows** in the brain's own derived rows (§19 scorecard below).

## Blockers

**B1. Learning has never run in the live brain.** NOW §2, blueprint §13, §19 row 1.
- **What the body shows:** `select bind,made,count(*) from gate where bind='proc' group by 1,2` returns told 856, core 5, and nothing derived.
- **No learning activity at all:** 0 learn runs, 0 guess runs, 0 sleep runs, and 0 `guesses` rows.
- **Why it can't happen:**
  - The sixth works its lists in a fixed order: shift, gap, imbalance, guesses, questions, parked, slow (`50-learning.lay:520`). Learn is reached only from `slow`, the last list.
  - New words are spawned at about 57 a minute (about 3,000 an hour), so the lists in front of it never empty.
- REPORT §3.1 calls this "a root-level limit" that time will fix. Five and a half hours of rows show it is structural.

**B2. The sixth doesn't choose; it walks.** Blueprint §12.1 says it "chooses by the progress it expects."
- **It walks a line:** its subjects climb by exactly 1 a second (#14200 at 06:55 to #15880 at 07:27). That is 1,713 subjects with 0 repeats, and no balance signal in the choice.
- **Its source checks do nothing:** 97.7% of the source-checks it splits have an empty subject (`at=145 subject=[]`, 3,176 of 3,251), so nothing is checked.

**B3. Sleep can never start.** §9.6: it asks "when its active memory passes a mark or after a long quiet."
- **It asks only once, and only on talk:** the ask fires only on talk input (`20-memory.lay:276`), and only once (`sleep-asked`). The 01:42 ask (mem 2847) is still standing, on a connection that closed.
- **It is far past its own mark:** `sleep-mark` is 500, and active memory is 63,396 rows.
- **So nothing that runs in sleep has ever run:** no HC, no back-propagation, and no search for formulas asleep. Every memory is still active and exact: 0 condensed, 0 highlights.

**B4. The core-value check can be bypassed.** §15: "A born check runs before every SAY, every CALL outward, and every WRITE to the brain's own processes."
- **The raw acts check nothing:** the SAY, CALL and WRITE.proc physics gates do no check of their own (`physics.go:929-962`, `:651`).
- **Learning writes processes unchecked:** both lines that write a process call bare `write-proc`, not `write-proc-checked` (`50-learning.lay:54` fit-write, `:275` gen-keep). `refused` speaks with raw `say` (`60-core.lay:134`).
- **The check itself is rewritable:** the checking processes `core-check`, `say-word`, `call-word` and `write-proc-checked` are made=told, not core. The kernel protects only the 5 core gates and 5 core rows.
- **The brain can lay files to itself:** told-ends isn't marked, so the brain can send a lay file to its own lay socket through `src-sh`.
- DECISIONS F and REPORT §2 both claim every process write is checked.

**B5. CALL is an unrestricted shell, and "stay home" is only a word filter.** §15 value 4. Still open (their #11).
- **What's laid:** `sh -c`, `go build` and `gcc` are laid as **grounded** sources (`40-sources.lay:22-24`), and the kernel runs whatever arguments the brain composes (`ports.go:193-198`).
- **Its own programs count as grounded:** output from its own programs starts at grounded trust, so it can ground itself.
- **Nothing keeps it home:** the start script limits memory only, with no network or file confinement. On hp, the brain's user must never touch postgres or ollama, and nothing enforces that.

## Major

**M1. An idle beat writes a blank memory row every second.** §0 rule 2, §12.
- **The rows:** `select count(*) from mem where kind='run' and outcome='ended' and body=''` returns **18,961**.
- **The kernel writes them:** `end()` writes the row itself (`run.go:423-428`), with a home chosen in Go (`physics.go:968-975`). DECISIONS 26 ("a run that ENDs itself writes nothing") and REPORT ("idle beats write nothing") are both contradicted.
- **The rate:** about 12,000–15,000 timeline rows an hour with nobody talking.

**M2. The same run doesn't land in the same row.** §9.2.
- **Pairs since the resume:** 763 signatures have 2 rows each, and `seen>1` = 0 in every hour from 03 to 07.
- **Across the whole body:** 935 signatures have more than one row (1,956 rows).
- **Receipts can point at the wrong memory:** `run.go:255-256` reuses an old id, and `physics.go:526-533` then writes a new one. The same-row choice is still made in Go.

**M3. Every word of a definition becomes a "grounded" fact.** §10.2 ("compares what the text implies"), §18 (no relationship from the builder's head), NOW §12.
- **The rule:** `new-desc … 'state-grounded write-rel` (`40-sources.lay:322,333`) relates every definition word to the headword as `r-describes`, held **grounded**. Thesaurus words become `r-same`, grounded.
- **The count:** 31,818 of 52,281 relationships are `r-describes|grounded`.
- **Who does the describing:** the top "describers" are `n` (the keyboard key gate, 386 lines), `of`, `the`, `or`, and "a" (the prime w-something).
- **Nonsense results,** for example `hi r-same age` held grounded.

**M4. Every newborn is an imbalance, by your own placement rule.** §5.5, §5.6.
- **The cause:** a new gate is spawned on its neighbour's point (DECISIONS B), and `two-at-one-point` runs at birth (`50-learning.lay:504`).
- **The result:** all 13,603 imbalance rows are birth gates (births per hour = imbalance rows per hour), and none was ever worked (`last=first` on all of them).
- **Real collisions too:** 522 points hold 2,179 unrelated gates. One point holds 36 meanings (homogeneous, foe, fiasco, smiled …). 1,258 gates sit at the exact origin.

**M5. The answer ladder takes the first item, so the guess rung is never reached.** §0 rule 3, §10.4, §10.6.
- **First relationship wins:** `rung-know-first: =0` (`30-questions.lay:293`) answers with the other end of the subject's first relationship, unlabeled. With 52,000 relationships, sources and guessing are effectively never reached.
- **First-only recurs elsewhere:** `guess-pick =0`, `gen-mate =0` (one memory, not "two or more"), and `fit-b =0` (fits from one pair).
- **Result:** 0 guesses ever. REPORT's "then a labeled guess (w-maybe)" has no rows behind it.

**M6. A found formula would be kept before it is tested.** §13.1: "If it predicts them, it is kept."
- `gen-keep` spawns and binds the process before any test (`50-learning.lay:275`).
- Its holes are filled with w-something; nothing tries which relationship links them.

**M7. Belief is cut to two terms, and trust is dead.** §10.3.
- **The weighing:** belief = use count × 0.1 + strength (`30-questions.lay:178`). Error history, trust, supporting knowledge and the expected-outcome inequality are all missing.
- **Trust:** all 8,400 trust rows have right=0 and wrong=0; `write-trust` is never reached.
- **Contradictions left standing:** 123 pairs hold both r-same and r-opposite, for example `polite r-same civil` (contradicted) next to `polite r-opposite civil` (grounded).
- **What it says:** every belief speaks the told string `"because #142 yes"`, the only thing said in 33 minutes, 21 times. #142 has no label, and it never says "no".

**M8. Facts and sense choices were laid from the builder's head.** §18, and your own LAY-NOTATION §5.
- **Opposite pairs laid as told facts:** good/bad, big/small, before/after, above/below, far/near, live/die and want/don't-want (`10-told.lay:389-404`). Only yes/no is named by the blueprint.
- **A told relationship:** `rel w-not r-derived-from r-opposite`.
- **Sense picks:** `label w-something something thing a`, `label w-move move to`, in→inside, up/down→above/below, time→when.

**M9. Source text is filtered and cut outside the encoder.** §4.1.6 ("no stop words"), §10.2 ("read like any other input").
- **A told cap:** the scripts return the headword plus the first 40 letter-only words.
- **A stop list in all but name:** any word whose gate is bound is skipped (`40-sources.lay:322-327`), which covers every prime label.
- **Definitions aren't read as actions:** "a reading run … runs nothing" (DECISIONS D).

**M10. Every subject goes to all 17 sources.** §5.3 and §10.4, cheapest first. Still open (their #21).
- 1,291 CALLs for 76 subjects, about 17 each, including "vb" and "their".

**M11. Unknowns explode instead of shrinking.** §12.1 goal: fewer unknowns.
- **The rate:** about 3,000 gates spawned an hour, from etymology scraps and HTML (participe, participium, fr, mw, parser, defdate, font, vb), all labeled English.
- **Most never get defined:** 14,558 of 15,005 spawned gates have no definition line.

**M12. The told base has become a program.** Guide §4, "The programming language".
- **The mix:** 2,633 tokens, 39% of them stack moves (dup/drop/swap/over/rot), plus 602 branches.
- **Born processes as told code:** source-check is 54 procs (338 tokens), reading 65 (225), the sixth 83 (201), core-check 40 (184), and believe 28, 13 of which unpack one list.
- REPORT's "mean 3.2 tokens" hides this.

**M13. Go still decides; the brain can't read or change it.** Owner, 10-19: logic that decides must be neuron code. Blueprint §4.2.
- **Credit for right/wrong:** WRITE.mark compares against the word `"yes"`, then adds right or wrong to every shard of the trail. That is awake back-propagation in Go (`physics.go:591-611`).
- **Hopping on its own:** after 8 misses the kernel hops to the head with no shard (`run.go:323-334`), using a hidden constant.
- **Worth and scheduling:** trigger worth is multiplied, and triggers under the floor are **cut** (`run.go:357-360`, still open, their #14; §12.2 says nothing is cut). Scheduling and parking happen in Go (`run.go:482-501`). The sixth gets only idle beats, with a hardcoded 64-step slice (`run.go:521-527`).
- **FIND.row is a scan:** it walks a whole kind list and picks the oldest (`physics.go:889-902`). That contradicts DECISIONS 81, and those lists only grow.
- **Hidden constants:** 64 evaluation steps, a 60-second CALL timeout, 64 KiB output, a 20 ms poll.
- **COMPARE and arithmetic rules in Go:** any difference counts as "more", and divide-by-zero gives +Inf (`physics.go:1014-1111`).

**M14. Kernel size and growth risks.** §4.2: past 2,000 lines, something leaked.
- **Size:** 3,370 lines (REPORT still says 3,292), with 104 physics bindings against the blueprint's 20. Still open (their #4).
- **RAM only grows:** deleted memories stay in `s.mems`, `memKind` and the RAM timeline (`physics.go:776-781`), and every body is held in RAM.
- **A full table scan per deleted memory:** commit deletes timeline rows with `DELETE … WHERE mem=?`, which scans every timeline row (`store.go:587`).
- **Placement cost grows:** it scales with a gate's relationship count. Gate 294 has 469 relationships. There were 32,587 MOVE lines against 21 SAY lines in 33 minutes.
- **Current RAM:** 273 MB at 07:40 under the 2 GB cap, growing about 1.6 MB a minute.

**M15. Kernel text reaches speech and memory, and blanks stand in for absent.** §5.4, §14.
- **Kernel text:** unlabeled gates are said as `#n` (`run.go:184`). Outcomes are stored as text: "ended" 18,962, "born" 15,007, `#n` 14,299.
- **Blanks and placeholders:** `mem.prev` is 0 on every row. `gate.miss` is −1 on all 16,257. Home = 0 means "none". An error, a timeout and empty output all become `""`.

**M16. The talk socket lets anyone be anyone.** Mode 0666, and `/who NAME` sets the speaker (`ports.go:84-96`). Any local account can speak as the owner.

## Done right

- **No LLM was called:** the friend source is gated behind the owner's yes and is marked as a guess.
- **Core rows are intact, and the kernel refuses writes to them.**
- **The second time is a hop** for typed sums.
- **Placement does move by relationships** when one lands.
- **Contradictions between sources** are now detected and kept.
- **The build guarded the machine after the hang:** earlyoom, a 2 GB cap with no swap, and dry runs capped.
- **DECISIONS and the REPORT's "what doesn't work" are mostly candid.**

## What to fix first (in this order)

1. **B4/B5, the core values:**
   - route every SAY, CALL and process write through a check the brain can't rewrite, or remove;
   - make the checking processes core;
   - take `sh`, `go` and `gcc` off the grounded list.
2. **B1, B2 and B3, the core of the test:**
   - the sixth must choose by expected progress, not by a fixed list order and gate ids;
   - sleep must be asked for again, without needing talk;
   - learn must be reachable.
3. **M1/M2:** no blank rows; the same run goes in the same row, decided in neuron code.
4. **M3, M8, M9:**
   - stop laying a relationship for every definition word, and stop holding it as grounded;
   - remove the told facts and sense choices;
   - read the definition as input.
5. **M13, move the deciding out of Go:** credit for right and wrong, the 8-miss auto-hop, cutting triggers, the FIND.row scan.
6. **M12:** cut the told program back toward the root level.
