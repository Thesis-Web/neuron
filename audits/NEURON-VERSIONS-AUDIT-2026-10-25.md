## The four tests, in your words

1. **A neuron is its own table** with DNA rows (arrival, remainder, trigger); prompt → encoder → brain. (Draft §2.1; you, 10-19 21:20: "THE BRAIN IS A DATABASE OF INDIVIDUAL NEURONS... IT IS NOT ONE BIG FUCKING TABLE".)
2. **A run assembles the SQL and mother pastes it**, births included. (Draft §2.6: "A trigger cannot create in the sense that a trigger happens and presto something happens in the sql. A string of sql happens as a run put together by the neurons from the run table and outputed as the string to the mother so the mother can then place that string of code into the sql prompt.")
3. **Mother decides nothing and works no data.** (Draft §2.6: "The mother is just a router and a traverser. That's it.")
4. **Only the table-making neurons, the hop and the trigger are hand-laid; everything else is built by typed runs; nothing outside the brain thinks.** (Handoff §0.)

Marks: **yes** / **half** (the test holds for part of the path and fails for the rest, said where) / **no**.

## Answer

None of them did it correct end to end. Not one version passes all four tests, and three pieces of the design have never been built by anyone: memory and timeline as runs, writing the DNA as a run, and a brain that holds only numbers.

Where to step back to: **v1's shape**, not any page. v1 (10-19) is the smallest build with a table per neuron, one trigger per neuron, an exec-only 14-line mother, one shard sequence, spaces as gates, and the BUILD run that turns a line's words into the SQL mother runs. It has two wrong parts, both named by you on 10-20: the birth is a template inside `g3`, and the walk is by position (`pos`, "look ahead"). The new v18 fixed exactly those two (birth by the born run; one gate trigger that hits or writes the shard) and nothing else about it should be kept: not the Python-generated born line, not the templates inside the gate trigger, not my `source`/`define` SQL, not the text in the tables.

Everything from v13 to 17.3 is the other lineage: a rule block I wrote in v15 and carried forward byte for byte through v16, 16.1-16.4, 16.7-17, and patched in 17.1-17.3. Its one correct piece, the `;` compile, is v1's BUILD in another form. There is nothing in that lineage to step back to.

The old v18 of 10-16 is the one you called "the most correct we ever had" on 10-19 at 21:55. Its mother and its end-of-run paste were right. Its neurons were rows in shared tables, which is why v1 was built the next hour.
