Owner, 2026-10-23, answering the v15 report:
- **"no do not tell the brain its name yet."** The E6 W-b anchor (state self.name told at birth) is not to be laid. The v15 page's preset "E6 2" does exactly that; drop it in the next version.
- **Nothing hand-placed in the graph.** "the graph is not a graph of words, its a graph of meanings, and those meanings are held in place by their relationships." v15 fixes the 14 actions, 40 SQL words, 16 physics tables, ports and 7 sources at chosen spots; the owner called that control ("you are choosing to place things like a control freak instead of building the system correct to do the work itself"). Every node, core ones included, should sit only where its relationships (16-20 of them) pull it.
- **Meanings are not only silicon:** a meaning may move the silicon, the neurons, memory, sources, or the run; it can differ per DNA row and per run; memory and state shape it ("dog" -> my dogs -> hunting for one person, parks for another). Modifiers adjust another word's meaning in that run.
- **Ports should be neurons:** primary and secondary input likely one neuron hitting different DNA rows; output to user vs output to sources are runs of words (output, to, user, sources) whose meanings route; diff the two runs to measure what "user" and "sources" do. Same for define (as an action its job is clear and must be measurable) and before.
- **Correction, not a told rule, for the stale memory hop:** a wrong answer from a memory hop should mark that memory row incorrect in that situation and start a reasoning run (why was it wrong here); the teacher gives why/how/when/where; the brain updates its own processes. "How did you do that?" twice back to back expects two different answers (the procedure behind the answer, then the procedure used to give the last output).
- **I/you is a perspective of the senses:** heard (text or microphone), said (brain output), secondary input from sources (like feel), the sixth's inner voice.
**Why:** these are the owner's design, stated after seeing v15. **How to apply:** check any next build against them; never re-add the name anchor or fixed positions without the owner. Related: [[project_neuron_physics_and_meaning_results_20261022]], [[feedback_speak_in_brain_terms]].
